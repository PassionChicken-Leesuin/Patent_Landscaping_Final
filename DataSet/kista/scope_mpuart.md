# Domain scope — Augmented / Virtual / Mixed Reality (KISTA "MPUART", marine-plant context)

Owner-provided scope memo (definition-level; no patent labels).

## What this domain is about
Augmented reality (AR), virtual reality (VR) and mixed reality (MR) technology — the sensing,
tracking, registration and display techniques that overlay virtual content on, or immerse a
user in, a real/environment view. The KISTA topic frames it for marine-plant / offshore use,
but the core technology is AR/VR/MR itself (head-mounted displays, photorealistic,
geo-registered overlays).

## In scope (core)
- AR/VR/MR display and interaction: HMDs, see-through displays, integrated real+virtual
  environment rendering, photorealistic and geo-registered overlays.
- Tracking / registration / pose estimation that aligns virtual content to the real scene.
- Systems that augment a live view with contextual data (including, but not limited to,
  marine/offshore plants, platforms, ships, vessels, docks, offshore structures).

## Out of scope
- Plain 3D graphics, CAD or simulation with no augmented/virtual/mixed-reality view.
- Marine / offshore structures described without any AR/VR/MR element.
- Displays or optics unrelated to AR/VR/MR.

## Note
The domain is defined by the AR/VR/MR technology; the marine/offshore setting is the
application context in which it is used, not a hard requirement in every patent.
